# DemoRealvirtual — the sandbox project

This project ships with every realvirtual WEB installation. It is a **sandbox**:
open it, jog the drives, rearrange the layout, break it on purpose. Nothing here
is load-bearing for your own work.

## It arrives once, and then it is yours

`projects/demo-realvirtual/` is seeded with your **first** delivery and after that it
is an ordinary folder under `projects/` — yours to open, edit and break, and **never
overwritten** by an update. An update replaces everything outside `projects/` and
writes nothing inside it.

There is exactly one exception, and it is never automatic: if realvirtual sends you a
new version of the demo, we say so first and run it deliberately. That named replacement
lists every file it would replace or delete before it does anything, and it replaces the
folder with our current state exactly.

## Still: copy before you keep

If a demo scene is the starting point for something of yours, **copy it into your
own project first** (open the document, then *Save into project…*). Your own project
is never the target of such a replacement, so that is where work you want to keep
belongs.
